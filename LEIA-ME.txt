GAMA — OTIMIZAÇÕES DE STREAMING (PATCH INCREMENTAL)

O pacote inclui um aplicador que modifica somente:
  lib/screens/chat_screen.dart

O objetivo é preservar o fluxo atual de mensagens, TTS, anexos, projetos,
sincronização e modelos, enquanto:
- atualiza os tokens por ValueNotifier, sem setState da tela a cada token;
- revela o texto em uma fila suave e mostra cursor piscante durante a geração;
- reutiliza os widgets de Markdown de mensagens finalizadas;
- envolve cada item da conversa em RepaintBoundary e remove sombras com blur;
- ancora a mensagem enviada perto do topo e para de seguir quando o usuário rola;
- adiciona haptics leves ao enviar/copiar/parar;
- mostra o status no balão, incluindo consulta da web e leitura do projeto;
- avisa “Memória atualizada” quando o evento memorySaved chega.

COMO APLICAR (Windows/PowerShell)
1. Faça uma cópia/commit do seu projeto antes de alterar.
2. Extraia este ZIP.
3. Copie aplicar_streaming_gama.py para a raiz do projeto Flutter (a pasta que
   contém pubspec.yaml).
4. Execute:
     python aplicar_streaming_gama.py
     flutter analyze
     flutter test
5. Só gere o APK depois de resolver eventuais erros do analisador/testes.

SEGURANÇA DO APLICADOR
- O script não modifica arquivos até validar todos os trechos esperados.
- Se a sua versão local divergir do arquivo-base esperado, o script para sem
  escrever alterações. Nesse caso, não force a aplicação: envie o erro e a
  versão atual de lib/screens/chat_screen.dart para ajustar o patch.
- Antes de modificar, cria um backup timestamped de chat_screen.dart.

OBSERVAÇÕES
- A fila de revelação controla a apresentação, mas o objeto Message continua
  recebendo o texto completo dos eventos para manter contexto e persistência.
- Respostas por voz mantêm o comportamento existente: o texto é revelado pelo
  callback de início dos trechos de áudio, sem ser exposto antes da reprodução.
- O ambiente de criação do pacote não executou Flutter analyze/test/build; rode
  os comandos acima na sua máquina antes de publicar o build.
