CORREÇÃO HTTP 401 NO DOWNLOAD DE VÍDEOS — GAMA

Esta versão corrige o caso em que o provedor termina a geração, mas o download falha com HTTP 401. O endpoint de conteúdo da OpenRouter exige o cabeçalho Authorization: Bearer quando o URL aponta para openrouter.ai. O script agora envia essa autenticação apenas para o host da OpenRouter; não encaminha a chave para hosts de armazenamento externos.

O pacote também preserva a integração do gerador no chat e o MIME video/mp4 já incluídos na correção anterior. Altera no máximo:
- backend/app/routes/chat.py
- backend/app/core/video_gen.py
- backend/app/routes/artifacts.py

APLICAÇÃO
1. Extraia o ZIP na raiz do repositório gama, onde existe a pasta backend.
2. Abra o terminal nessa pasta e execute: python aplicar_correcao_video.py
3. Confira: git diff --check
4. Confira as alterações: git diff -- backend/app/routes/chat.py backend/app/core/video_gen.py backend/app/routes/artifacts.py
5. Faça commit/push e aguarde o redeploy do Railway.

O script cria backups antes de gravar e valida a sintaxe Python. Não altera Flutter, memória, voz, STT, drawer nem outras habilidades. A geração real ainda depende de OPENROUTER_API_KEY válida, VIDEO_GEN_ENABLED=true, modelo disponível e saldo do provedor. Não foi possível testar com as credenciais reais do Railway.
